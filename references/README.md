# References

- **REFERENCES.md** — every source the project uses, grouped into literature,
  datasets and software, each with a link and its access terms. Start here.
- **references.bib** — the same literature in BibTeX, for manuscripts.
- **pdfs/** — somewhere to keep downloaded papers. Not version controlled.

Provenance for the data files stored in this repository, including download
dates and original row counts, is in `../static_inputs/README.md`.

Add a source here in the same change that introduces it. A figure that reaches
the site before its citation reaches this file is a figure no reader can check.
