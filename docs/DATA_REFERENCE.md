## 1. How to read this

Each entity below is one CSV file in a run's app export, downloadable from that
run's release. For every column the type, whether it is ever empty, and an
example value are read from the data itself. The description is written only
where the column's meaning is established by the pipeline or by the upstream
dataset. **A blank description means the column is not documented, not that it
is unimportant** - it is left blank deliberately rather than filled with a
guess.

Two columns appear in every entity: `run_id` identifies the weekly run, and
`data_as_of` is the end of its data window. Together they make any row
traceable to the release it came from.
